Design Notes

Error Design

1) All errors are propagated up to and into the client's code.
2) All error messages that are meant for the client (pretty much all) are localized.
3) All strings that are logged (uses dbgLog() are not localized because they are for the Addon dev.
4) When Errors occur in the private layer, an error msg is generated and returned to the
client. At this level the error message is specified with the file and line number where the
error occurred. It looks like this:

    "[WoWThreadsLIb:41] Parameter is nil."

When it arrives at the public API stack frame, the calling function is added. so
that it now looks like:

    "[WoWThreadsLIb:41] Parameter is nil. thread:getId()"

Where thread:getId() is the thread function that called the private code in which
the error was generated.
